# Bridging Task Planning and Execution for Language-Conditioned Bimanual Manipulation

Project page for the paper, served with GitHub Pages.

- `index.html`: the whole page (text, figures, results, BibTeX).
- `static/images/`: figures, resized and compressed for the web.
- `static/css/`, `static/js/`: Bulma, Font Awesome and the page style.
